## Шаг 2. CSS: два состояния элемента

Любая анимация появления состоит из двух состояний:

1. **Начальное**: элемент невидим и сдвинут. Изначальный класс.
2. **Конечное**: элемент на своём месте и виден. Его включает JS, добавляя класс.

Между состояниями нужен `transition`.

```css
.reveal {
    opacity: 0;
    transform: translateY(40px);
    transition: opacity 0.6s ease, transform 0.6s ease;
}

.reveal.visible {
    opacity: 1;
    transform: translateY(0);
}
```

**Ваша задача:** для каждого класса из шага 1 написать начальное состояние и общий класс-«включатель» (назовите его `animate`).

- слайд слева: `translateX` с отрицательным значением;
- слайд справа: то же с положительным;
- «увеличение»: `scale(...)` меньше единицы;
- анимируйте только `opacity` и `transform`.

Обратите внимание, что изначальное скрытое состояние элемента описывается просто в классе (допустим `card`), а его новое состояние описывается в классе `visible`, который выдается рядом с `card` (`.card.visible`)

## Шаг 3. Создаём IntersectionObserver

Наблюдатель принимает два аргумента: **функцию-колбэк** и **объект настроек**.

Пример: страница рецептов, где нужно подсвечивать карточки блюд.

```js
const options = {
    threshold: 0.3,                    // сколько процентов элемента должно быть видно (0–1)
    rootMargin: "0px 0px -80px 0px"    // сдвиг границ области видимости
};

const recipeObserver = new IntersectionObserver((entries) => {
    entries.forEach((entry) => {
        if (entry.isIntersecting) {
            // сюда: что делать с элементом, который появился
        }
    });
}, options);
```

- `entries` это **массив** элементов, у которых изменилась видимость;
- `entry.target` это сам DOM-элемент;
- `entry.isIntersecting` равен `true`, когда элемент вошёл в экран.

**Ваша задача:** создайте свой observer. Подберите `threshold` и `rootMargin`. Внутри `if` () добавьте элементу класс `animate` через `classList.add`.

## Шаг 4. Подпишите элементы на наблюдение

Observer ничего не делает, пока вы не скажете, за кем следить. Метод называется `observe()`, и вызывать его нужно **для каждого элемента**:

```js
const cards = document.querySelectorAll(".recipe-card");

cards.forEach((card) => {
    recipeObserver.observe(card);
});
```

`querySelectorAll` принимает несколько селекторов через запятую. Используйте это, чтобы собрать все ваши анимируемые классы одним запросом.

**Результат шага:** при скролле блоки плавно появляются.

## Шаг 5. Анимация только один раз

Сейчас, анимация срабатывает, но observer продолжает следить за элементом вечно. Если анимация должна проигрываться **один раз**, перестаньте наблюдать за элементом после срабатывания. Найдите в документации метод observer, который скидывает эту логику.

## Шаг 6. Появление по очереди (stagger)

Карточки с `stagger-item` должны появляться не все сразу, а с задержкой: первая, через 0,2 с вторая, ещё через 0,2 с третья.

Когда сработал один элемент из группы, найдите всех его **соседей** и каждому добавьте класс с задержкой, зависящей от **порядкового номера**.

```js
const items = parentElement.querySelectorAll(".notice");

items.forEach((item, index) => {
    setTimeout(() => {
        item.classList.add("shown");
    }, index * 150);
});
```

- Вы получаете родителя сработавшего элемента (`parentElement`)
- Запускаете через `setTimeout` каскадную анимацию
- Скидываете с группы слушателя

## Шаг 7. Дополнительные эффекты

**7.1. Полоска прогресса скролла.** Нужно слушать событие `scroll` на `window` и считать, сколько процентов страницы прокручено:

```js
// процент = прокручено / (вся высота − высота окна) * 100
```

Нужные свойства: `window.scrollY`, `document.documentElement.scrollHeight`, `window.innerHeight`. Результат запишите в `style.width` элемента-полоски.

**Пример 1: структура обработчика.** Кнопка «Наверх» показывается, только когда страницу прокрутили вниз:

```js
const topButton = document.querySelector(".back-to-top");

window.addEventListener("scroll", () => {
    // здесь на каждое событие скролла считаем нужное значение
    console.log(window.scrollY);
});
```

Сначала просто выведите `window.scrollY` в консоль и посмотрите, как число меняется при скролле. (Чтобы понять какие там вообще значения)

**Пример 2: формула процента на другом блоке.** Допустим, у вас есть окно чата с собственной прокруткой, и нужно узнать, насколько оно прокручено:

```js
const chat = document.querySelector(".chat");

chat.addEventListener("scroll", () => {
    const maxScroll = chat.scrollHeight - chat.clientHeight; // сколько всего можно прокрутить
    const percent = chat.scrollTop / maxScroll * 100;
    console.log(percent.toFixed(1) + "%");
});
```

Логика та же, что нужна вам. Отличие в том, что у страницы эти значения лежат в других свойствах. Не забудьте, что `style.width` принимает **строку с единицей измерения**, например `"45%"`.

**7.2. Шапка меняет прозрачность.** Если прокрутили больше 100px, шапка становится чуть темнее. Событие `scroll` и `element.style.background`.

**Пример: условие с двумя ветками.** Боковое меню меняет цвет после 250px прокрутки:

```js
const sidebar = document.querySelector(".sidebar");

window.addEventListener("scroll", () => {
    if (window.scrollY > 250) {
        sidebar.style.background = "rgba(20, 20, 60, 1)";
    } else {
        sidebar.style.background = "rgba(20, 20, 60, 0.5)";
    }
});
```

Обратите внимание, что нужны **обе** ветки. Без `else` меню потемнеет и больше никогда не вернётся назад. Посмотрите в CSS, какой цвет и какая прозрачность у шапки сейчас, и выберите два значения, которые заметно отличаются.

**7.3. Плавный скролл по якорям.** Для каждой ссылки, чей `href` начинается с `#`:

- отмените стандартный переход (`event.preventDefault()`);
- найдите секцию по `href`;
- вызовите у неё `scrollIntoView` с параметром `behavior: "smooth"`.

Селектор для таких ссылок: `a[href^="#"]` (`^=` значит «начинается с»).

**Пример 1: перебор ссылок и чтение атрибута.** На странице есть оглавление, и нужно понять, куда ведёт каждая ссылка:

```js
const tocLinks = document.querySelectorAll(".toc a");

tocLinks.forEach((link) => {
    link.addEventListener("click", (event) => {
        event.preventDefault();                 // браузер не прыгает сам
        const id = link.getAttribute("href");   // например, "#chapter-2"
        console.log("Клик по ссылке на", id);
    });
}); 
```

Проверьте, что в консоли появляется нужный `href`, а страница при этом **не прыгает**. Это значит, что `preventDefault` работает. Дальше остаётся найти элемент по этой строке и прокрутить к нему.

**Пример 2: настройки `scrollIntoView`.** Метод принимает объект с параметрами. Вот как он выглядит на кнопке, которая прокручивает к блоку FAQ:

```js
const faqBlock = document.querySelector("#faq");

document.querySelector(".jump-btn").addEventListener("click", () => {
    faqBlock.scrollIntoView({ behavior: "smooth", block: "center" });
});
```

Параметр `behavior` отвечает за плавность, а `block` за то, где блок окажется на экране (`"start"`, `"center"`, `"end"`). Попробуйте разные значения `block` и выберите подходящее. Учтите, что шапка у вас фиксированная и может частично закрывать заголовок секции.
Селектор для таких ссылок: `a[href^="#"]` (`^=` значит «начинается с»).
